# 🍅 Сбор Краснодара

Аркада на чистом JavaScript + Canvas. Герой бежит по бесконечной дороге,
собирает летящие овощи и банки томатной пасты **«Краснодар»**, уворачивается
от тракторов, машин, тётечек и дядечек. Восемь столкновений — и игра
заканчивается надписью **«Офигеть ты влетел, Вась!»**.

## ✨ Возможности

- 🏃 Бесконечный раннер с параллаксом (облака / дома / кусты)
- 🥕 Летающие репки, капуста, помидоры и банки пасты «Краснодар»
- 🚜 Трактора, машины, тётечки и дядечки в качестве препятствий
- 📊 Два счётчика: собранный Краснодар и овощи
- ❤️ 8 жизней, мигающий счётчик при низком запасе
- 🔊 Конфигурируемые звуки: мелодия, столкновение, Краснодар, овощи
- 📱 Работает офлайн, без сборки и зависимостей

## 🚀 Быстрый старт

Просто открой `index.html` в браузере:

```bash
git clone https://github.com/ТВОЙ_НИК/krasnodar-game.git
cd krasnodar-game
# открой index.html в браузере
```

Если хочешь через локальный сервер (удобно для разработки):

```bash
# Python 3
python -m http.server 8000

# или Node.js
npx serve .
```

И перейди на `http://localhost:8000`.

## 🎮 Управление

| Клавиша            | Действие       |
| ------------------ | -------------- |
| `Пробел` / `↑`     | Прыжок         |
| Клик по кнопке     | Начать заново  |

Мелодия включится после первого клика или нажатия клавиши — так требуют
браузеры (autoplay заблокирован без жеста пользователя).

## 🔊 Конфигурация звуков

В правом верхнем углу — четыре поля. Вставь URL аудиофайла или оставь пустым.

| Поле          | Когда играет                          | Системный звук (если пусто)  |
| ------------- | ------------------------------------- | ---------------------------- |
| Мелодия       | Фон, зациклено                        | Генерируемая мелодия         |
| Столкновение  | При любом ударе (появляется «МАНАТЬ!») | «Бум» из двух тонов          |
| Краснодар     | При поимке банки пасты                | Мажорный «дзынь»             |
| Овощи         | При поимке овоща                      | Мягкий «блип»                |

Все системные звуки генерируются через Web Audio API — без файлов и задержек.

## 🧠 Как это работает

- **Параллакс.** Облака, дома и кусты сдвигаются на разную долю `cameraX`:
  дальний план — медленно, ближний — быстро. Герой при этом стоит на месте.
- **Физика прыжка.** `hero.vy += GRAVITY`, затем `hero.y += hero.vy`.
  При достижении земли скорость обнуляется, `onGround = true`.
- **Столкновения.** Классическая AABB-проверка: два прямоугольника
  пересекаются, если `a.x < b.x + b.w && a.x + a.w > b.x && ...`.
- **Спавн.** Каждые N кадров создаётся новый объект справа за экраном.
  Интервалы рандомизированы, чтобы игра не казалась линейной.
